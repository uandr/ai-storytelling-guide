# 🎧 Персонализированный AI-гид со сторителлингом

---

## 📌 О проекте

TL;DR: делаем AI-гид с ML-пайплайном для создания сценария аудио/видео-экскурсии по интересам пользователя.

Под катом:
204  Персонализированный AI-гид со сторителлингом
Трек: DL Уровень сложности: middle/pro
Руководитель: Николаев Михаил 
Классические аудиогиды и экскурсии плохо адаптируются под конкретного посетителя: маршрут, язык повествования и глубина погружения фиксированы заранее. Израильский стартап Xsite решает эту проблему, создавая для музеев и туристических объектов AI-гидов с генеративным видео, закадровым текстом и адаптивной подачей истории под конкретного пользователя, а также инструменты для быстрого создания такого контента без больших продакшн-команд.
В рамках проекта предлагается разработать сервис, который по описанию объекта (музея, исторического центра, парка) и открытым источникам (Wikipedia, краеведческие тексты, архивы) автоматически генерирует персонализированный сценарий аудио/видео-экскурсии: подбирает факты и истории под интересы пользователя (история, архитектура, гастрономия, локальные легенды), выстраивает драматургию рассказа и адаптирует стиль повествования (детский, познавательный, атмосферный).
В расширенной постановке система должна уметь подстраивать маршрут и длительность рассказа под темп передвижения пользователя (геопозиция) и генерировать закадровую озвучку через TTS с эмоциональной интонацией, соответствующей содержанию истории.
Итоговое решение — мобильный веб-сервис или Telegram-мини-приложение, которое по выбранной локации и профилю интересов пользователя генерирует персонализированный аудиогид.
Задачи: сбор и структурирование фактического материала по объектам показа, построение пайплайна генерации сценария с учётом стиля и интересов пользователя (LLM + контроль фактологической точности), разработка модуля драматургии/сторителлинга (структура рассказа, кульминации, переходы между точками маршрута), интеграция TTS с эмоциональной окраской, привязка сценария к геопозиции.
Проект будет интересен тем, кто хочет поработать на стыке NLP-генерации, контроля галлюцинаций LLM (важна фактическая точность истории) и мультимодальной генерации (текст + аудио), а также получить опыт создания продукта в сфере travel-tech и культурных индустрий.
